# Валютный кошелёк

После регистрации можно войти в свой аккаунт и работать с портфелем:
покупать и продавать валюту, проверять балансы кошельков и стоимость портфеля.
У каждого пользователя свой портфель. Данные записываются в JSON
и остаются после закрытия программы.

Курсы криптовалют программа получает из CoinGecko, а фиатных валют —
из ExchangeRate-API. Загруженные курсы сохраняются в кэше. Если нужный курс
устарел, программа пытается получить его заново.

Если купить 0.01 BTC, баланс BTC увеличится на 0.01. При продаже он уменьшится
на указанное количество. Стоимость сделки в USD показывается для справки,
переводов между кошельками нет. Это упрощённый вариант торговли из задания.

## Запуск

Нужны Python 3.12 и uv. В папке проекта выполните:

```console
uv sync
uv run project
```

Для ExchangeRate-API нужен ключ из личного кабинета сервиса.
В PowerShell его можно указать перед запуском программы:

```powershell
$env:EXCHANGERATE_API_KEY = "ваш_ключ"
uv run project
```

## Пример работы

Сначала создайте аккаунт и войдите в него, затем обновите курсы:

```text
register --username petr --password 1234
login --username petr --password 1234
update-rates
buy --currency BTC --amount 0.01
show-portfolio
sell --currency BTC --amount 0.005
get-rate --from BTC --to USD
show-rates --top 2
exit
```

Команда `help` показывает список команд и их аргументы.
По умолчанию стоимость портфеля считается в USD. Чтобы посмотреть её в евро,
используйте `show-portfolio --base EUR`.

`update-rates` загружает курсы из обоих источников. Можно выбрать один:
`update-rates --source coingecko` или `update-rates --source exchangerate`.
Для обновления каждые пять минут запустите в отдельном терминале:

```console
uv run python -m valutatrade_hub.parser_service.scheduler --interval 300
```

Настройки находятся в pyproject.toml. Файлы с данными создаются в папке data,
логи операций и обновлений — в logs.

Проверка кода: `uv run ruff check .`. Сборка: `uv build`.
